# recipes

The goal of this project is to implement a variety of NLP models on a dataset of recipes.

Targeted functionalities:
- Input a recipe, get recommended similar recipes
- Request a similar ingredient to replace one you don't have
- Suggest a list of new recipes a user may like, based on a list of favourite foods
- Create a new recipe based known recipe data
- Generate made up recipe names
- Take a list of ingredients and suggest a meal the user will like
